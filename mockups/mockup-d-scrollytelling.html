HEIMDALL
CLI & AGENT TOOLKIT v1.1.0 on npm

heimdall-agent Sync Engine

A curated, pre-packaged toolkit with battle-tested agent personas and skills ready to use. Optimized to drop right into your coding assistants so you never have to configure skills manually again.

GitHub Repo npm package
The Problem

AI coding tools (Antigravity, Claude Code, Codex) start completely empty. Setting up roles, skills, and testing guardrails across each tool by hand is repetitive and constantly drifts out of sync.

What Heimdall Does

Delivers 56 curated skills and 10 specialized agent roles (reviewers, testers, architects) in one command. Uses live NTFS junctions so all your tools stay synchronized from a single source.

$ npm i -g heimdall-agent && heimdall sync
ENVIRONMENT AUDITOR v1.1.0 on npm • Zero Dependencies

gc-helper GhostCLI Bridge

Helps you configure and set up your environment if you use ghostcli.cloud. Automatically detects your installed AI tools, wires up endpoints and tokens, and verifies your connection in seconds.

GitHub Repo npm package
The Problem

Configuring GhostCLI across Claude Code, VS Code, Codex CLI, and Hermes requires hunting down different config files, base URLs, and environment variables for each tool. One typo breaks everything.

What gc-helper Does

Scans your workstation, auto-configures your proxy endpoints with one command, and pings models in real time to filter dead routes and show actual connection latency. Zero external npm dependencies.

$ npx gc-helper status
